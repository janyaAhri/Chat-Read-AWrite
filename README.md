# Chat Story (แชทนิยาย)

ส่วนเสริม SillyTavern อ่านโรลเพลย์ได้สองแบบ พิมพ์ต่อได้ในหน้าอ่านทั้งสองแบบ
- **แชทนิยาย**: แตะหนึ่งครั้ง ข้อความเด้งหนึ่งฟองพร้อมเสียง
- **นิยาย**: อ่านแบบหนังสือ แบ่งเป็นบท มีหน้าเปิดบท (ชื่อเรื่อง บทที่ ชื่อบท) ย่อหน้าย่อบรรทัดแรก แตะกลางจอซ่อนแถบ ปุ่ม Aa ปรับขนาดตัวอักษร ระยะบรรทัด พื้นหลัง และฟอนต์ได้ทันที

## ติดตั้ง
SillyTavern > Extensions > Install extension > วางลิงก์ GitHub ของ repo นี้

## ใช้งาน
- **หน้าอ่าน** (ค่าเริ่มต้น): บอทตอบเสร็จแล้วเปิดหน้าอ่านทับแชท แตะจอหรือกด Space เพื่ออ่านต่อ ลูกศรซ้ายย้อนกลับ Esc ปิด
- **พิมพ์ในหน้าอ่าน**: พิมพ์แล้วกดส่ง ข้อความเข้า SillyTavern จริง บอทตอบกลับมาต่อท้ายในหน้าเดิม แตะอ่านต่อได้เลย ระหว่างรอมีจุดพิมพ์ กดปุ่มเดิมเพื่อหยุดได้
- **แชทหลักเป็นฟอง**: ข้อความในแชทกลายเป็นฟอง ข้อความใหม่แตะไล่เปิดทีละฟอง
- ปุ่มรูปหนังสือบนข้อความ = อ่านข้อความนั้นย้อนหลัง
- เมนูไม้กายสิทธิ์: อ่านแบบนิยายแชท · อ่านทั้งแชท · ปรับแต่ง

## ปรับแต่ง (เมนูสามจุดในหน้าอ่าน หรือปุ่ม "ปรับแต่งทั้งหมด")
- **หน้าตา**: ธีมสำเร็จรูป 8 แบบ ค่าเริ่มต้นขาวดำ ปรับสีเองได้ 11 จุด
- **หน้านิยาย**: ขนาดตัวอักษรและระยะบรรทัดแยกจากแชทนิยาย · เรียกว่า บทที่ / ตอนที่ · ย่อหน้าบรรทัดแรก จัดเต็มแนว ระยะย่อหน้า ความกว้างหน้ากระดาษ ส่วนที่เราเขียน (เหมือนเนื้อเรื่อง / มีเส้นกำกับ / ซ่อน)
- **ตัวอักษร**: ฟอนต์ไทย 21 แบบ หรือพิมพ์ชื่อฟอนต์อื่นเอง ขนาดตัวอักษร ระยะบรรทัด
- **ฟองแชท**: ความมน ความกว้าง รูปตัวละคร 4 แบบ บรรยาย 3 แบบ ชื่อเหนือฟอง สีชื่อ ฝั่งของเรา
- **เสียง**: 9 แบบ + อัปโหลดไฟล์เสียงเอง ความดัง เสียงต่างกันรายตัวละคร เสียงบรรยาย สั่นบนมือถือ
- **ตัวละคร**: สีฟองและเสียงแยกรายตัว
- **การอ่าน**: โหมด เปิดเอง ช่องพิมพ์ Enter ส่ง ข้อความก่อนหน้า จุดพิมพ์ ความเร็วเล่นอัตโนมัติ

## คอมเมนต์และรีแอคชันท้ายย่อหน้า (หน้านิยาย)
เปิดที่ ปรับแต่ง > คอมเมนต์ (ปิดไว้เป็นค่าเริ่มต้น)
- กล่องคอมเมนต์ท้ายทุกย่อหน้าเหมือนแอพอ่านนิยาย แม้ยังไม่มีคนเม้นท์ แตะแล้วเรียกคนอ่านมาคอมเมนต์ย่อหน้านั้น หรือเขียนเองได้ (ไม่ใช้โทเคน)
- ย่อหน้าที่มีคนคอมเมนต์จะขึ้นรีแอคชัน (ชอบ ปัง ขำ เศร้า ตกใจ โกรธ) พร้อมจำนวน
- **ใครเลือกว่าจะเม้นท์บรรทัดไหน**
  - **โมเดลเลือกตอนเขียน** (ค่าเริ่มต้น): ทุกบท โมเดลเลือก 1–3 บทพูดหรือการกระทำที่คนอ่านน่าจะรีแอค ติดป้าย `[c]` ไว้ ระบบลบป้ายออกจากข้อความให้ · ~23 โทเคนต่อเทิร์น ฝากไปกับคำตอบโรลหลัก · ตอนเรียกคอมเมนต์ส่งแค่บรรทัดที่เลือก (กับย่อหน้าที่แตะ)
  - **คนอ่านเลือกเอง**: ส่งทั้งบท ไม่เพิ่มโทเคนในโรลหลัก แต่ต่อครั้งแพงกว่า
- **คนอ่านประจำ**: มาคอมเมนต์ทุกครั้งที่เรียก อยู่ในการเรียกเดียวกัน
  - **janyaahri** มีเป็นค่าเริ่มต้น เปิดปิดได้ ใช้คาร์เดิมครบ รู้ผิดรู้ถูก เปลี่ยนรูปได้
  - กด **+ เพิ่มคนอ่าน** ใส่ชื่อ รูปจากเครื่อง (ย่อเหลือ 96×96 ไม่ทำให้ไฟล์ตั้งค่าอ้วน) และนิสัยคร่าว ๆ (ไม่เกิน 300 ตัวอักษร) · แก้ ลบ เปิดปิดได้ทีละคน
- แก้ไข (ข้อความและรีแอคชัน) และลบคอมเมนต์ได้ทุกอัน
- คอมเมนต์เก็บไว้กับข้อความในแชท แก้ข้อความแล้วคอมเมนต์เก่าจะหายไปเอง

### คอมเมนต์มาเอง (1.9)
เปิดเป็นค่าเริ่มต้น เงื่อนไขผสมกันได้ อันไหนถึงก่อนก็มา
- โมเดลเลือกบรรทัดตอนเขียน → มาในบทนั้นทันที
- ครบทุก N ข้อความของบอท (ค่าเริ่มต้น 3) นับจากครั้งล่าสุดที่เรียก ครบแล้วมาแน่ ๆ
- สุ่มโอกาสต่อข้อความ (ค่าเริ่มต้น 30%)
- ตั้งเป็น 0 = ไม่ใช้ข้อนั้น · ใช้ได้ทั้งโหมดหน้าอ่านและในแชทหลัก

### โทเคน
- เปิดไว้เฉย ๆ ไม่ใช้โทเคน จะใช้ก็ต่อเมื่อเรียกคนอ่าน (หรือเปิดให้เรียกเอง: แบบโมเดลเลือกเรียกเฉพาะบทที่มีบรรทัดที่เลือก · แบบคนอ่านเลือกมีด่าน **เจอคีย์เวิร์ด** หรือ **ทุกบท**)
- ก่อนเรียกบอกตัวเลขประมาณ หลังได้คอมเมนต์บอกตัวเลขจริง (ส่งไป · ได้กลับ) นับด้วยตัวนับของ SillyTavern
- หน้าปรับแต่งมี **"ดูว่ามีอะไรบ้าง ทำไมใช้เท่านี้"** แยกให้ดู: เนื้อบทที่ส่งไป · คนอ่านประจำ · คำสั่ง + รูปแบบคำตอบ · คำตอบที่ได้กลับ
- ตัวอย่างจริงในบทไทย 5 ย่อหน้า มีคนอ่านประจำ 2 คน: โมเดลเลือกบรรทัด ~415 โทเคน · คนอ่านเลือกเองทั้งบท ~1,071 โทเคน (ส่วนที่หนักที่สุดคือเนื้อบท ภาษาไทยกินโทเคนกว่าภาษาอังกฤษ 2–3 เท่า)

## พิมพ์และส่ง
- พิมพ์แล้วกดส่ง ข้อความเข้า SillyTavern จริง
- ช่องว่างแล้วกดส่ง = ให้บอทเขียนต่อ เหมือนปุ่มส่งของ SillyTavern
- ใช้คู่กับส่วนเสริม [Auto-Closer](https://github.com/nattaphat010447/nutho_autocloser) ได้ ช่องพิมพ์ในหน้าอ่านจะปิดเครื่องหมายให้ตามที่ตั้งไว้ใน Auto-Closer (ต้องเปิด Chat textboxes ไว้)

## ข้อความที่เราพิมพ์
- ในเครื่องหมายคำพูด "..." = คำพูด ส่วนที่อยู่นอกเครื่องหมาย = บรรยาย
- \*ดอกจัน\* = บรรยาย
- ไม่มีเครื่องหมายเลย = ระบบเดาให้ (ขึ้นต้นด้วยชื่อเรา หรือเล่าการกระทำ = บรรยาย · ประโยคพูดคุยสั้น ๆ = คำพูด) ตั้งให้เป็นคำพูดหรือบรรยายเสมอได้

## รูปแบบที่บอทเขียน (แบบแชทนิยาย)
```
[สถานที่ / เวลา]
บรรยายฉากหนึ่งบรรทัด
ชื่อ: คำพูด
ชื่อ (คิด): ความคิด
```
ส่วนเสริมใส่คำสั่งนี้ให้บอทเอง ส่วนแบบนิยายจะสั่งให้เขียนเป็นย่อหน้าต่อเนื่อง และขึ้นต้นด้วยชื่อบท `## ชื่อบท` ปิดได้ทั้งสองแบบ

## ประหยัดโทเคน (1.5)
คำสั่งรูปแบบที่แทรกเข้าโรลหลักทุกเทิร์น ย่อเหลือสั้นที่สุด นับด้วยตัวนับของ SillyTavern:
- แชทนิยาย 302 → 59 โทเคนต่อเทิร์น
- นิยาย 137 → 38 โทเคนต่อเทิร์น

## สลับนิยาย ↔ แชทนิยาย และแยกว่าใครพูด (1.8)
- ปุ่มในแถบบน: หน้านิยายมีปุ่มแชท หน้าแชทนิยายมีปุ่มหนังสือ แตะแล้วสลับทันที บทต่อไปบอทเขียนตามแบบใหม่
- บทที่เขียนเป็นร้อยแก้ว เปิดเป็นแชทแล้วแยกคนพูดให้เอง ดูได้หลายทาง
  - ชื่อก่อนหรือหลังคำพูด (“…” เคนพูด · เคนกระซิบ “…”) ชื่อที่ใกล้และมีคำว่า พูด ถาม ตอบ ตรัส กระซิบ ฯลฯ ชนะ
  - เขา/เธอ + พูด = คนที่ถูกเอ่ยถึงล่าสุด
  - ย่อหน้าที่มีแต่คำพูด สลับกับคนที่เพิ่งพูด หรือพูดต่อจากคนเดิม
  - แบบบทละคร (ชื่ออยู่บรรทัดเดียว คำพูดบรรทัดถัดไป) · ขีดยาว — คำพูด — เคนว่า · เปิดเครื่องหมายแล้วไม่ปิด
  - เครื่องหมายคำพูดทุกแบบ “ ” " " 「」 『』 «» ＂＂ · ‘ ’ กับ 『』 ที่ไม่มีคำพูดกำกับ หรือมีคำว่า คิด นึก ในใจ = ความคิด
  - ชื่อเรียกอื่น (พี่มิ, คุณหนู) ชี้ไปชื่อหลัก · ชื่อยาวชนะชื่อสั้นที่ซ้อนอยู่ข้างใน
  - ชื่อใหม่ที่ไม่เคยเจอ เดาจากตำแหน่งติดคำพูด และชื่อที่ถูกเอ่ยซ้ำในบท (ภาษาไทยไม่เว้นวรรคก็เจอ) ตัดคำอย่าง เขา เธอ ชายหนุ่ม ทิ้ง
  - ชื่อเราเหมือนชื่อตัวละคร: ในข้อความของบอทยังอยู่ฝั่งบอท · ตั้ง "นี่คือตัวเรา" ให้ชื่อไหนก็ได้ ฟองไปอยู่ฝั่งเรา
- ในแชทหลักแบบฟองก็แยกคนพูดแบบเดียวกัน

## ตัวละครรายการ์ด (1.8)
- แท็บตัวละคร แสดงเฉพาะตัวละครของการ์ดหรือกลุ่มที่เปิดอยู่ การ์ดอื่นที่ชื่อซ้ำตั้งแยกกัน ไม่ปนกัน
- ชื่อใหม่ที่เจอในเรื่องเข้ามาเอง · ปุ่ม + เพิ่มเอง · ลบแล้วไม่ดึงกลับ (คืนได้)
- ตั้งรูปจากเครื่อง (ย่อเหลือ 96×96) สีฟอง เสียง ชื่อเรียกอื่น และ "นี่คือตัวเรา" ได้ทีละตัว
- รูปดึงจากการ์ดในแชทนี้เท่านั้น ในกลุ่มใช้รูปของการ์ดที่ส่งข้อความนั้นจริง กลุ่มที่มีสองการ์ดชื่อเดียวกันก็แยกสีและรูปกัน
- สีและเสียงที่ตั้งไว้ก่อน 1.8 (แบบรวมทุกการ์ด) ยังใช้ได้ แก้เมื่อไหร่จะย้ายมาเป็นของการ์ดนั้น

## 1.10
- คอมเมนต์ใช้ได้ในแชทนิยายด้วย: แถบ "ความคิดเห็น" ใต้ข้อความของบอท ทั้งในหน้าอ่านและแชทหลัก แตะแล้วเห็นคอมเมนต์ทั้งบทแยกตามบรรทัด แก้ ลบ เขียนเอง เรียกใหม่ได้
- คอมเมนต์มาเอง (ครบรอบ · สุ่ม · โมเดลเลือก) ทำงานทั้งแบบนิยายและแชทนิยาย
- จำว่าอ่านถึงไหนแยกแต่ละแชท: อ่านทั้งแชทต่อจากฟองล่าสุด · หน้านิยายกลับไปบทและตำแหน่งเดิม
- แยกคนพูดแม่นขึ้น: ชื่อสั้นไม่ไปจับในคำอื่น (ต้น ≠ ตื่นเต้น) · ดูเพศจาก ค่ะ/ครับ และ เธอ/เขา · เรียนเพศจากแชทและคำอธิบายการ์ด · ตั้งเพศเองได้ในแท็บตัวละคร · "เขา" ที่ไม่มีชื่อหมายถึงตัวละครหลักก่อน
- ฝั่งขวามีแต่ข้อความที่เราพิมพ์จริง บทของตัวเราที่บอทเขียนอยู่ซ้ายพร้อมชื่อ (เปลี่ยนได้ที่แท็บฟองแชท)

## 1.11
- แก้คอมเมนต์ไม่ขึ้น: เผื่อความยาวคำตอบให้โมเดลที่คิดก่อนตอบ (Gemini, R1 ฯลฯ) และภาษาไทย · ตอบว่างเปล่าลองใหม่ให้เอง · คำตอบที่โดนตัดกลางทางเก็บส่วนที่ครบไว้
- ไม่เงียบอีกแล้ว: คอมเมนต์อัตโนมัติมาหรือพลาดจะมีแจ้งเตือน · แท็บคอมเมนต์โชว์ผลครั้งล่าสุด พร้อมคำตอบดิบจากโมเดลไว้ดูสาเหตุ
- ตั้ง "ครบทุก" หรือ "สุ่ม" หรือเปิด "คอมเมนต์มาเอง" = เปิดคอมเมนต์ให้เลย · ถ้ายังปิดอยู่มีป้ายเตือน
- แชทนิยาย: ไอคอนคอมเมนต์เล็ก ๆ ชิดขวาแบบหน้านิยาย

## 1.12
- คำตอบคอมเมนต์ที่ JSON พัง (มีเครื่องหมาย " ในคอมเมนต์ จัดหน้าแปลก หรือโดนตัดท้าย) อ่านได้แล้ว ไล่เก็บทีละคอมเมนต์
- เลขย่อหน้าคลาดนิดหน่อยปัดไปย่อหน้าที่ใกล้ที่สุด
- ปุ่ม "อ่านคำตอบนี้ใหม่ (ไม่ใช้โทเคน)" ในแท็บคอมเมนต์ กู้คอมเมนต์จากคำตอบที่เคยพลาด

## 1.13
- ตั้งจำนวนคอมเมนต์เองเป็นตัวเลข: คอมเมนต์ต่อย่อหน้า 1–10 · จำนวนย่อหน้าที่มีคนเม้นท์ 1–12 (ค่าเดิม น้อย/ปกติ/เยอะ ย้ายมาให้เอง)
- ที่ให้คำตอบขยายตามจำนวนที่ตั้ง คอมเมนต์เยอะก็ไม่โดนตัด

## 1.14

  - ให้โมเดลคิด: ฉากเด็ดคอมเมนต์เยอะ ฉากเรียบน้อย ไม่เกินที่ตั้ง
  - สุ่ม: ตั้งช่วงต่ำสุด–สูงสุด ทั้งต่อย่อหน้าและจำนวนย่อหน้า สุ่มใหม่ทุกครั้ง แต่ละย่อหน้าได้ไม่เท่ากัน
- ใช้ได้ทั้งตอนคนอ่านเลือกย่อหน้าเอง และตอนโมเดลเลือกบรรทัดไว้
